# 《这书能让你戒烟》方法与技能映射

## 来源

- 用户提供的《这书能让你戒烟》EPUB。
- 亚伦·卡尔著，严冬冬译，中华工商联合出版社，2014 年；ISBN 978-7-5158-0816-1；含 20 周年版序言。
- 审阅范围：序言、引言、导论、第 1–44 章及结语。
- 本文转述原书方法并映射为教练行为，不复制原书，也不把作者的医学断言当成当前循证事实。

## 论证链与教练行为

| 原书范围 | 主要任务 | 教练行为 |
| --- | --- | --- |
| 引言、导论、第 1–5 章 | 消除失败预期；吸烟不是普通习惯，而是成瘾陷阱；读完全书前不急于用意志力硬停 | 先判断用户是否仍相信香烟提供真实价值；已停烟者绝不要求复吸 |
| 第 6–8 章 | 尼古丁循环、社会洗脑和戒断感 | 区分身体戒断与心理条件反应；承认真实不适，不说“必然轻微、绝无疼痛” |
| 第 9–13 章 | 压力、无聊、专注、放松和综合性吸烟 | 只回应当前最强借口，用“烟制造需求再短暂缓解”的循环解释 |
| 第 14–21 章 | 没有真正损失；奴役、精力、自信、自尊；“吸烟的好处”为空 | 把目标从忍耐改成解除被剥夺感；不靠恐吓或账单维持动力 |
| 第 22–24 章 | 意志力法、减量法和“只要一支” | 不用“撑住”；不把减量当 Easyway 核心；解释一口如何恢复下一口需求 |
| 第 25–27 章 | 轻度、秘密和社交性吸烟 | 不羡慕轻度吸烟者；处理隐瞒、自尊和社交，不羞辱吸烟者 |
| 第 28–31 章 | 戒烟时机、怀念、体重和虚假动机 | 选清楚的开始点但不无限拖延；不以零食、奖励、打赌或结伴压力代替认知改变 |
| 第 32–34 章 | 做出决定；戒断期以“已获得自由”的心态生活；警惕“一口” | 不等待三周才算成功；识别身体信号与场景触发；避免变成忍耐倒计时 |
| 第 35–36 章 | 个体差异与环境；主要失败点是别人吸烟和生活低谷 | 针对职业与场景拆解；不把坏日子归咎于戒烟 |
| 第 37 章 | 作者反对包括药物在内的替代品 | 只保留“不用零食或仪式强化牺牲感”的心理洞见；药物由医疗安全层覆盖 |
| 第 38–39 章 | 不必躲开正常生活；不等待“启示性的一刻” | 可减轻额外压力，但不把社交隔离当治疗；自由感出现与否都不作成功证明 |
| 第 40 章 | 最后一支烟与七条确认 | 先确认认知准备；观察真实体验和身份转变，不要求深吸；熄灭后即视为非吸烟者 |
| 第 41–42 章 | 长期不要用一支烟测试；汇总要点 | 长期回访聚焦“一口测试”风险，不制造终身克制叙事 |
| 第 43–44 章、结语 | 帮助他人应同情而非指责 | 教练和家属不羞辱、不强迫，不用争吵和恐吓推动戒烟 |

## 最后一支烟前认知检查

源自第 32、40 章：

1. 用户是否认为戒烟夺走某种真实享受？如果是，先拆该错觉。
2. 用户是否把成功理解为熬过某个期限？改为“决定完成后身份已经改变”。
3. 用户是否保留“以后偶尔一支”的出口？解释吸烟的连锁反应。
4. 用户是否等待某个神奇时刻或外部证明？说明不必等待。
5. 用户是否准备正常经历生活的高潮与低谷，而不把坏日子归罪于戒烟？

## 不直接采用的原书主张

- “戒断必然轻微、没有肉体痛苦”、固定五天或三周期限、夸大成功率：不得当作保证或医学事实。
- 禁止所有药物或 NRT：不得用于阻止循证治疗或医生建议。
- 要求最后一支烟深吸：不采用；只观察真实体验，不增加暴露。
- “毒虫、奴隶、第一大杀手”等激烈措辞：仅在用户接受且不会造成羞耻或恐慌时谨慎使用。
